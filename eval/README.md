# eval：AI 評測與黃金測試集

**只放模擬資料或已去識別化的資料。**真實院內文件不可以放進這裡（ADR-0006、NFR-05）。

| 資料夾 | 內容 | 對應需求 |
|---|---|---|
| `boot02-extraction/` | 從辦法抽取證據規格的技術驗證與測試集 | BOOT-02、BOOT-03、AIS-07 |

每個測試集包含：
- `policies/` 或其他輸入資料；
- `expected/` 標準答案（人工撰寫）；
- `prompt.md` 提示詞（有版本號）；
- `score.py` 評分腳本；
- `runs/` 每次執行的輸出，依「日期-模型-提示詞版本」命名。
