# 04 · 商業與合規檢核表

> 本文件為工作清單，非法律意見。簽約前請律師審閱。

## 智財歸屬
- [ ] 智財（程式碼、資料模型、證據規格範本、prompt、黃金測試集方法）歸屬醫點，不以個人名義持有
- [ ] Git repository 擁有權移轉到醫點組織帳號（目前在個人帳號下，需規劃移轉時點）
- [ ] 每位貢獻者（含未來工程師、外包）簽署著作權讓與／職務著作約定
- [ ] 第三方套件授權清冊（避免 AGPL 等傳染性授權進入產品核心）

## 利益衝突（安南）
- [ ] 對安南書面揭露個人與醫點的關係及本系統的商業利益
- [ ] 安南相關採購、評選、驗收程序本人迴避
- [ ] 安南定位為**免費試點**，簽訂試點合作／保密協議，明定資料使用範圍
- [ ] 試點資料：不出院、去識別化後才可進黃金測試集，並取得書面同意

## 合作模式
- [ ] 與資訊公司合作：對方投標、導入、維運；醫點收授權費或分潤
- [ ] 合約要點：授權範圍、分潤計算、維運責任、資料處理者義務、終止後資料返還
- [ ] 原始碼託管（escrow）：合約要求時再設
- [ ] 部署文件從第一天就維護（見 [deployment.md](deployment.md)）

## 著作權（標準條文）
- [ ] ISO 條文：系統只存結構（編號、標題），`text_policy = structure_only`，資料庫 trigger 強制
- [ ] 評鑑基準：確認發布機關的授權條件後決定 `summary` 或 `full`；確認前一律 `summary`
- [ ] JCI 標準：同 ISO，預設 `structure_only`

## 資安與隱私
- [ ] 預設地端部署，文件與模型推論不出院
- [ ] 程式碼稽核可委外
- [ ] 關鍵資安稽核（滲透測試、架構審查）另找獨立廠商
- [ ] 個資盤點：會議紀錄可能含病人個案討論 → 需界定處理範圍與遮蔽策略
- [ ] 留存期限與刪除機制（`retention_months`、稽核軌跡 `audit_log`）

## 範圍守則
- 守住醫療機構，不跨一般產業
