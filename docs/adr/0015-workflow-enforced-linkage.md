# ADR-0015 以流程強制關聯；未確認的檔案不列入佐證

| 項目 | 內容 |
|---|---|
| 狀態 | 已採納 |
| 日期 | 2026-11-03 |
| 相關需求 | TASK-03、TASK-10、TASK-11 |
| 取代／修訂 | — |
| 討論來源 | [2026-11-03 需求與架構討論](../discussions/2026-11-03-requirements-architecture.md) |

## 背景
舊 KM 的關聯靠使用者自律，最後退化成網路硬碟。

## 決策
- 從任務上傳時，關聯自動綁定。
- 自由上傳的檔案進待歸類區，設有處理時限；逾時列入燈號並通知品管。
- 未經系統確認的檔案，不列入佐證清單。

## 理由
靠流程強制，不靠紀律；同時給使用者走系統流程的實際理由。

## 影響
無。
