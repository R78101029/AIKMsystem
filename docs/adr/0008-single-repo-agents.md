## 背景
一開始決定 Agent 分析服務另開程式庫。後來確認 Agent 的輸出就是系統設定（組織、證據規格、對應關係），和核心資料模型綁得很緊。

## 決策
Agent 放在主程式庫，作為模組；商業上的區隔改用授權開關處理。

## 理由
避免在兩個程式庫各維護一份資料模型。

## 影響
需要設計授權與功能開關機制。
