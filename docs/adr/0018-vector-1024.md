# ADR-0018 向量維度暫定 1024，存放於 pgvector

| 項目 | 內容 |
|---|---|
| 狀態 | 暫定 |
| 日期 | 2026-11-03 |
| 相關需求 | AIS-02 |
| 取代／修訂 | — |
| 討論來源 | [2026-11-03 需求與架構討論](../discussions/2026-11-03-requirements-architecture.md) |

## 背景
需要做語意檢索，而且希望維運單純。

## 決策
`chunk.embedding vector(1024)`，使用 HNSW 餘弦索引，並記錄 embedding 模型。

## 理由
單一資料庫，維運負擔低；1024 維可以涵蓋多數地端多語 embedding 模型。

## 影響
不同院區或客戶若使用不同維度的模型，需要以新的資料庫遷移腳本新增欄位，或改用分表；在 MVP-1 前再檢討。
