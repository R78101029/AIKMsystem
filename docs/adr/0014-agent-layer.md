## 背景
多數機構沒有導入 ISO，文件很亂，無法直接以評鑑條款建立系統。過去需要專家逐單位訪談盤點。

## 決策
- 架構新增 Agent 編排層，位於使用介面與應用模組之間。
- **導入分析 Agent**：匯入辦法 → 抽出應產生的紀錄 → 產生證據規格草稿 → 依單位產生確認清單 → 對應條款 → 找出雙向缺口 → 產出報告與可以直接匯入的設定。
- **稽核監控 Agent**：定期巡檢逾期、缺漏、需重審、未登錄的新檔案，並產出週報。
- 規則：Agent 只能呼叫應用模組的介面；以受限的服務帳號執行；每一步都留紀錄；只產出建議與通知，寫入正式資料必須經人確認。

## 理由
把專家的工作從「從零訪談」變成「審核草稿」；從辦法抽取要求，與一致性稽核使用同一個 AI 能力。

## 影響
掃描既有檔案必須以唯讀方式在院內執行，並取得書面授權。
