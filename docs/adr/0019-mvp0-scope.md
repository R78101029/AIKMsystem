## 背景
需要盡早驗證兩個核心假設：(1) 能不能從辦法自動長出證據規格；(2) AI 檢查準不準。

## 決策
- 主線：匯入辦法 → AI 抽取證據規格草稿 → 人審定稿 → 任務 → 上傳 → 歸類 → 要素檢查 → 一致性稽核 → 人審 → 燈號 → 佐證清單。
- 時程約 2 人月；時間不足時，簡化介面，不砍主線。
- 使用醫院通用的模擬資料，並埋入已知缺陷；模擬資料同時當作第一批黃金測試集。

## 理由
一次驗證產品最核心的兩個假設。

## 影響
MVP-1 的範圍隨之擴大，需要重估工作量。
