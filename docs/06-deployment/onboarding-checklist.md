導入新機構時逐項確認。完成的檢核表屬於該機構的導入紀錄，**存放在院方或專案文件區，不進入本程式庫**。

## A. 合約與合規
- [ ] 合作／試點合約、保密協議已簽署
- [ ] 資料處理範圍、個資遮蔽策略已確認
- [ ] 導入分析 Agent 的掃描授權（唯讀範圍）已取得書面同意
- [ ] 模型方案（地端／客戶自己的雲端／醫點代管）與資料政策已確認

## B. 前置對接（ORG-07～11）
- [ ] 組織架構來源：人事系統匯出檔／Entra ID／AD／手動維護
- [ ] 單位清單（含院區、委員會、專案小組）已匯入並驗證
- [ ] 人員清單與唯一識別（員工編號或 email）已確認
- [ ] 成員關係（一人多單位、主管、委員任期）已匯入
- [ ] 人事異動的同步方式與頻率已確認

## C. 機構特殊流程訪談（BOOT-12，需要人工）
- [ ] 文件生效流程（例：委員會通過 → 公文簽核 → 生效）
- [ ] 各類文件的核准層級
- [ ] 公文等外部核准紀錄的取得方式
- [ ] 文件編號規則
- [ ] 文管模式：外部文管／內建文管（DCT-01）

## D. IT 環境
- [ ] 登入方式（內建／OIDC／LDAP）
- [ ] 儲存來源（O365 Sites.Selected 授權範圍／NAS／內建）
- [ ] 副本存放位置與容量規劃（DOC-04、DOC-11）
- [ ] 通知管道（SMTP）
- [ ] 主機、模型推論硬體、備份方案

## E. 資料與存量
- [ ] 辦法、SOP 全集已匯入（BOOT-01）
- [ ] 證據規格草稿已產出，單位確認清單已回收（BOOT-02～05）
- [ ] 舊系統資料匯出（含標籤、路徑、日期）已完成（TASK-12）
- [ ] 新流程的起始日已訂定；歷史存量的整理範圍已訂定（ADR-0017）

## F. 上線
