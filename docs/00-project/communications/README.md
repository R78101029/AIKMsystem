# 對外溝通紀錄

存放提供給院內單位或外部對象的說明資料存檔。依 ISO/IEC 29110 PM.2，對外溝通內容要留存，以便追溯「當時告訴對方的是什麼版本」。

| 日期 | 對象 | 檔案 | 線上版本 | 依據 | 說明 |
|---|---|---|---|---|---|
| 2026-11-03 | 文管中心、資訊室 | [2026-11-03-system-overview-dc-it.html](2026-11-03-system-overview-dc-it.html) | Artifact 版本 1（私人連結，由專案負責人分享） | 需求規格書 v0.1、ADR-0001～0019 | 系統示意：舊 KM 問題對照、證據規格概念、四種角色的操作畫面、ISO 文件管制對照、整合點與資安原則、待議問題。全部為模擬資料 |

## 規則

- 存檔內容必須與當時發出的版本一致；內容更新時另存一份新檔，舊檔不覆寫。
- 不可以包含真實院內資料、個資或合約內容。
- 對方回饋的意見，整理到 `docs/discussions/`，必要時轉為需求變更。
